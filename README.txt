# J-Mart Website

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — search, categories, sorting, cart and demo login
- `images/` — the 10 product images supplied in this conversation

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, `script.js`, and the complete `images` folder to the root of your `J-mart` repository.
2. In the repository, open **Settings → Pages**.
3. Under Build and deployment, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then Save.
5. Wait for GitHub Pages to publish the site.

Note: Login and checkout are demonstration-only. Real authentication, payments and order processing need a backend.
